# PRO_7.1_SerialNr_Readout_For-Intune

This repository contains PowerShell scripts designed to be deployed via Microsoft Intune (Proactive Remediations) to collect hardware inventory data, including:
- Docking stations
- Active monitors
- USB Printers
- BIOS serial numbers

The collected data is exported to a CSV file and uploaded securely to an Azure Blob Storage container.
